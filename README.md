# 📊 E-Commerce Customer Lifecycle & RFM Analytics Dashboard

## 🚀 Project Overview

This project analyzes customer purchasing behavior using RFM (Recency, Frequency, Monetary) analysis and visualizes insights through an interactive Power BI dashboard connected with PostgreSQL.

The dashboard helps businesses identify:

* High-value customers
* Loyal customers
* Customer churn opportunities
* Revenue trends
* Customer lifecycle behavior

# 📊 Dashboard Insights

* Loyal Customers contribute the highest revenue.
* Potential Loyalists form the largest customer segment.
* At Risk customers indicate retention opportunities.
* Monthly revenue trends reveal business growth patterns.
